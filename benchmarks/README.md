# P17.1 — измерительный стенд Comrade

Этот модуль не изменяет код приложения и не читает настоящие задачи пользователя.

Запуск из корня репозитория (Node.js 20+):

- node benchmarks/comrade-performance.js — полный набор
- node benchmarks/comrade-performance.js --check — быстрая проверка
- node benchmarks/comrade-performance.js --json — машиночитаемый результат

В GitHub Actions автоматически выполняются оба сценария проверки и полный замер. Результаты находятся в логах шагов workflow.

## Сценарии

Создаётся детерминированный набор из 100, 500, 1000, 3000 задач: восемь колонок, верхние и вложенные задачи, теги, приоритеты, чек-листы и сроки.

Замеряются реальные функции Comrade: renderBoard (построение оболочки доски), getVisibleTasks (поиск, фильтры), sortTasks, countVisibleDescendants, subtree, getAfterElement (поиск карточки под пальцем). Для каждого сценария выводятся медиана и p95 семи серий вызовов в миллисекундах на операцию.

## Что результаты НЕ измеряют

Это синтетический Node.js benchmark, а не тест на планшете. Он не включает реальное создание HTML каждой карточки, CSS, WebView, GPU, анимации, вложения или IndexedDB. Замер renderBoard показывает стоимость организации элементов и алгоритмов, **но не реальную задержку построения доски на Android**. GitHub Actions работает на машинах с переменной нагрузкой: измерения между разными запусками могут отличаться.

Для корректного сравнения P17.1 с P17.2 повторять на одинаковом Node и железе, желательно несколько раз. Жёстких порогов скорости в CI нет. Перед оптимизацией жестов дополнительно измерить длительность кадра на реальном планшете.
