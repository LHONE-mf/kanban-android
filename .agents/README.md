# Vendored engineering skills

This directory contains selected, unmodified `SKILL.md` workflows and supporting checklists from [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills), licensed under MIT (see `docs/third-party/addyosmani-agent-skills-LICENSE`).

Skills are in `skills/<name>/SKILL.md`; shared references are in `references/`. Agents should consult `AGENTS.md` for project-specific routing and verification rules.

These are **repository-local instruction files**, not executable Android features and not a ChatGPT account-level skill installation. Some upstream skills refer to additional upstream checklists that have not been vendored; consult the source repository if required. Updates are manual; review upstream changes before copying them.
